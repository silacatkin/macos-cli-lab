# System Information 
## uname -a (unix name -a all yani hepsi):
-işletim sistemi ve sistem çekirdeği hakkında bilgi verir 
-Darwin, macOs çekirdek adıdır.
-yabancı bir sistemde sistem hakkında bilgi edinmek için ilk yapılan işlem komutudur.
## uname -r (release)
-işletim sisteminin sadece çekirdek sürümü hakkında bilgi verir.
-sürüm numarası yazılır örneğin (25.5.0 gibi) 
*kısaca; uname -a sistem detayı uname -r kernel sürümünü verir.
